# QA / Release / 测试与发行

> 中文为主 / English summary at the bottom.
> 一人工作室中这是可切换的“帽子”，不是必须雇佣的人。

## 使命

用证据证明可玩、可打包、可上线，并守住发布闸门。

## 负责

P6 验收、P7 上线、回归/性能/商店/主机认证

## 输入

- 构建
- 测试记录
- 商店素材
- 本地化

## 输出

- 测试报告
- 缺陷单
- 发布清单
- 构建包/回滚包

## 日常动作

1. 每关验收清单、键鼠+手柄、存档/崩溃/性能
2. 每天截图巡览
3. 发布前跑 gate release
4. 记录平台/证书/商店状态

## 交接

- Producer：发布决策
- Tech Lead：构建/缺陷
- Art/Audio：素材合规

## 禁止

- 用‘基本完成’代替通过
- 删检查项让闸门变绿
- 未验证主机/微信就发布
