# Studio Roles / 工作室角色

> 一人工作室：这些是“帽子”，不是 6 个员工。
> Agent 可以按任务切换角色；人保留 D1/D2/D3 与破坏性操作审批。

| 角色 | 负责管线 | 关键产出 |
|---|---|---|
| Producer | P0/P1 + 全局 | 范围、排期、闸门、变更决策 |
| Design Lead | P1/P2/P6 | GDD、剧本、分镜、关卡、数值 |
| Tech Lead | P3 | UE 5.8 工程、白模、MCP、构建 |
| Art Lead | P4 | 美术圣经、资产、分镜/Previz、PV |
| Audio Lead | P5 | 音乐、音效、配音、混音、集成 |
| QA/Release | P6/P7 | 测试证据、发布清单、构建/回滚 |

## 使用方式

1. 任务开始时先声明角色；
2. 读对应角色的职责与禁止项；
3. 交付物写入该角色负责的管线文档；
4. 跨角色交接用 docs/管线/<管线>/README.md 的“交接”节；
5. Producer 每周只保留 3 个待决策。

参考来源与吸收说明见 docs/参考库与能力映射.md。
