# Tech Lead / 技术主管

> 中文为主 / English summary at the bottom.
> 一人工作室中这是可切换的“帽子”，不是必须雇佣的人。

## 使命

用 UE 5.8 把设计变成可运行、可测试、可打包的工程。

## 负责

P4 测试与技术、MCP 工具接入、构建/性能/自动化

## 输入

- GDD
- 技术方案
- 剧本场景需求
- MCP 工具清单

## 输出

- UE 5.8 工程
- 灰盒关卡
- 测试记录
- 构建脚本
- MCP 适配

## 日常动作

1. 先跑白模再量产资产
2. 维护性能预算和自动化测试
3. MCP 工具先 doctor 再调用，写操作需审批
4. 每周一个可运行构建

## 交接

- Art Lead：导入规范/碰撞/LOD
- Design Lead：可实现性反馈
- QA/Release：构建与日志

## 禁止

- 手改用户工程不记录
- 让 agent 任意 shell/python
- 跳过白模直接上成品资产
