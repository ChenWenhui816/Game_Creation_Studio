# 资产卡规范 / Asset Card

> 中文为主 / English summary at the bottom.
> 目标：每个资产都有身份、来源、许可证、版本和状态，agent 和人都能查。

## 1. 文件位置

- 索引：.gameconsole/assets.json（可重建）
- 资产：assets/、art/Source/、art/Export/
- schema：schemas/asset_card.schema.json

## 2. 必填字段

id、path、kind、sha256、size、status。

## 3. 建议字段

license、source、provenance（AI 模型/提示词/种子/服务）、dcc_source、export_file、ue_path、import_settings、lod、faces、dependencies、stage、owner。

## 4. 状态机

untracked → draft → review → approved → in_game → deprecated

## 5. 扫描

~~~powershell
python scripts/asset_registry.py scan --project .
python scripts/asset_registry.py validate --project .
python scripts/asset_registry.py list --project .
~~~

扫描只读取文件并写索引，不移动/删除资产。

## 6. AI 资产强制字段

- model / service / prompt / seed / license
- 是否允许商用
- 是否经过人工重拓扑/UV/贴图
- 来源 URL 或服务订单号

## 7. 与变更单/冻结的关系

资产进入 in_game 前必须有验收单；修改已批准资产要建变更单；冻结快照记录资产哈希。

---

### English Summary

Every asset has a stable ID, hash, license, source and status.
AI-generated assets must record model/service/prompt/seed/license and whether retopo/UV/texturing was done by a human.
The registry is rebuildable; the local files remain the source of truth.
