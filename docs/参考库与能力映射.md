## 2. Donchitos：吸收了哪些

吸收：

- 三层工作室结构 → 压成 6 个可切换角色（agents/）；
- 7 阶段流程 → 8 条管线 + 8 道闸门；
- gate-check → 每管线 gate + Studio 控制台闸门；
- story/sprint/里程碑 → docs/工作室流程目录.md + 冲刺/里程碑模板；
- project.yaml 的配置思路 → gamecheck.json + .gameconsole/state.json；
- 模板化文档 → templates/（18 份）+ 管线 README/SKILL。

没有吸收：

- 49 个常驻 agent（一人工作室过重）；
- .claude/ 绑定（我们保持多 agent 兼容）；
- 网页游戏优先路径（我们 UE5 3D 主机优先）；
- 未经充分验证的引擎分支（我们只用 UE 5.8 锁版）。

## 3. gamedev-skills：吸收了哪些

吸收：

- SKILL.md 作为 agent 契约的结构；
- router “先识别项目/任务，再只加载相关技能”的思想；
- 引擎/任务/类型分层；
- “真实引擎验证/评测”的质量意识。

没有吸收：

- 79 个具体引擎技能（UE 部分后续按需引入，避免一次性塞满上下文）；
- 具体引擎代码/文档内容（尊重许可，按需适配并保留 NOTICE）。

我们的实现：

- docs/管线/*/SKILL.md：8 个管线契约；
- router/SKILL.md：8 管线路由；
- studio.py route "<请求>"：关键词路由 POC；
- docs/管线/README.md：人类入口。

## 4. agency-agents：吸收了哪些

- 角色不是“万能助手”，而是有职责、边界、交付物；
- 角色之间明确交接；
- 只保留 6 个角色，不引入整套 100+ agent。

## 5. UI UX Pro Max：吸收了哪些

- 用 `--design-system` 为“开发者工具 / 数据面板 / 暗色 / 高密度”生成设计方向；
- 采用其令牌结构：background/card/border/text/muted/accent/destructive/ring；
- 采用 Fira Sans/Fira Code 字体方向（本地回退，不引入外部字体请求）；
- 采用 Glassmorphism 的“低透明度层 + 1px 细边 + 背景模糊”，但控制用量；
- 采用 120 条 UX 规则中的可访问性/焦点/减少动效/触控尺寸/响应式；
- 未整体复制 725 个文件，只落地到 `console_web/styles.css` 与 `docs/UIUX设计系统.md`。

## 6. Superpowers：吸收了哪些

- 先澄清/设计再实现；
- 计划 → 执行 → 自测 → 证据 → 交付单；
- 子代理协作和可回滚；
- 没有把 Superpowers 作为运行时依赖。
