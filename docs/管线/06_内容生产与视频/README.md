# 06 · 内容生产与视频 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

把白模、资产、剧本、音频组装成完整可通关的游戏；PV/视频放到测试完成之后再做，避免过早投入营销素材。

## 什么时候用

P4 测试通过后进入；PV 在游戏测试完成、镜头与卖点确定后再启动。

## 输入

- 白模/关卡
- 资产库
- 剧本/任务
- 音频
- 测试结论与卖点

## 输出

- 全部关卡
- 敌人/Boss/收集
- 剧情/任务/UI
- docs/17_视频PV制作单.md（测试后）
- 周报与验收单

## 闸门

G6 全流程通关 + PV：内容量/验收/测试记录 + PV 制作单。

## English Summary

Assemble the complete game; produce PV/video only after testing when the selling points are proven. Gate G6 = playable content + PV document.
