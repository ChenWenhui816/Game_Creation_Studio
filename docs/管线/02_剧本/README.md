# 02 · 剧本与叙事 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

把故事变成可拍、可配音、可做美术、可做视频的上游生产包。

## 什么时候用

在当前阶段的**这个管线**需要产出/验收时使用；不要等所有前置 100% 完成才开始概念探索。

## 输入

- 立项书
- GDD 核心循环
- 世界观/角色想法

## 输出

- docs/14_剧本圣经.md
- docs/15_分镜与镜头表.md
- 场景/镜头/台词/配音 ID

## 步骤

1. 写一句话故事、主题、世界观、角色目标与弧光。
2. 做三幕/节拍表，把玩法节点映射到剧情节点。
3. 写场景表（SC-）、台词表（LINE-），标情绪/时长/本地化 key。
4. 写镜头表（SH-），标景别、机位、资产、音乐/音效 cue。
5. 交接：美术做概念/分镜，视频做 animatic/PV，音频做 VO/music。

## 验收闸门

**G2 剧本可拍**

## 工具

- gamecheck gate script
- LLM 辅助
- Studio 控制台

## 交接

P4 美术/视频：场景、角色、道具、分镜；P5 音乐/音频：VO、MUS、SFX。

## 文件位置

- 文档：docs/
- 阶段版本/冻结：stages/02_剧本/
- 证据：docs/evidence/
- 资产：assets/、art/Source/、art/Export/

## 注意事项

没有 ID 的剧本不能进入下游；不要先做视频再补剧本。
