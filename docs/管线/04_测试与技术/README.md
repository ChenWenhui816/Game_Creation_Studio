# 04 · 测试与技术 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

用 UE 5.8 做可玩灰盒，验证移动/相机/战斗/性能/存档；先证明能玩，再铺内容。

## 什么时候用

P3 概念与美术锁定后进入。白模先验证手感与性能，不要先堆资产。

## 输入

- GDD、技术方案
- 美术圣经/资产清单
- 剧本场景需求

## 输出

- UE 5.8 工程与灰盒关卡
- docs/04_关卡设计
- docs/10_测试记录.md
- 性能采样、盲测证据

## 闸门

G4 白模/测试可玩：文档阶段 2 + 数值自洽 + 盲测证据。

## English Summary

Build a playable whitebox and verify movement, camera, combat, performance and saves before content production. Gate G4 = whitebox/test evidence.
