# 03 · 白模与技术 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

用 UE 5.8 做出能跑、能跳、能玩的最小灰盒，验证玩法而不是画面。

## 什么时候用

在当前阶段的**这个管线**需要产出/验收时使用；不要等所有前置 100% 完成才开始概念探索。

## 输入

- GDD
- 技术方案
- 剧本场景需求

## 输出

- UE 5.8 工程
- 可玩灰盒关卡
- docs/10_测试记录.md
- 盲测证据

## 步骤

1. 建 UE 5.8 工程：目录、插件、输入、相机、角色。
2. 做 1 关灰盒：阻挡、高低差、战斗/交互、检查点。
3. 跑性能预算与自动化测试；截图/录屏。
4. 做盲测：3 人以上、记录卡点/时长/结论。
5. 冻结白模，进入美术/内容生产。

## 验收闸门

**G3 白模可玩**

## 工具

- UE 5.8
- UE MCP / Python
- gamecheck gate whitebox
- screenshots

## 交接

P4 美术：按灰盒比例做资产；P6 内容：扩关卡。

## 文件位置

- 文档：docs/
- 阶段版本/冻结：stages/03_白模与技术/
- 证据：docs/evidence/
- 资产：assets/、art/Source/、art/Export/

## 注意事项

白模不好玩，不要做量产资产；先砍机制。
