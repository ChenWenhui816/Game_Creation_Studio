# 03 · 概念与美术 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

先把概念、风格、色板、角色/场景锚点和资产清单定下来，再进白模与测试；避免“先做工程才发现美术方向不对”。

## 什么时候用

P2 剧本可拍后进入。不要等所有剧情 100% 完成才开始概念探索，但必须先有 1 个可玩的视觉锚点。

## 输入

- GDD、剧本场景需求
- 三个对标与美术偏好
- 资产预算/平台性能

## 输出

- docs/02_美术圣经.md
- docs/05_资产清单.csv
- 概念图 / 色板 / 风格锚点
- 资产管线验证记录

## 闸门

G3 概念与美术锁定：美术圣经完成 + 资产清单逐行校验。

## English Summary

Lock concept, style, palette, visual anchors and the asset list before whitebox/testing. Gate G3 = art bible + asset manifest.
