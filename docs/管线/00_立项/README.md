# 00 · 立项 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

把一句话想法变成一页纸、可判定、可停损的立项书。

## 什么时候用

在当前阶段的**这个管线**需要产出/验收时使用；不要等所有前置 100% 完成才开始概念探索。

## 输入

- 一句话想法
- 目标平台与主机优先级
- 可投入时间/预算
- 参考作品

## 输出

- docs/00_立项书.md
- 范围与不做清单
- 最大风险
- 目标体验

## 步骤

1. 回答 8 个问题：谁、做什么、为什么现在、平台、规模、风险、不做、成功标准。
2. 写 3 个对标，并说明我们不同在哪里。
3. 算产能：总时长 ÷ 每周可用小时；超过 20 周先砍范围。
4. 用陌生人复述测试：对方能否在 2 分钟内复述。
5. 冻结范围，进入标准管线。

## 验收闸门

**G0 立项书可复述**

## 工具

- 文档模板
- Studio 控制台

## 交接

P1 标准：GDD、美术圣经、技术方案、资产清单、数值表。

## 文件位置

- 文档：docs/
- 阶段版本/冻结：stages/00_立项/
- 证据：docs/evidence/
- 资产：assets/、art/Source/、art/Export/

## 注意事项

不要在立项阶段写 30 页策划；先证明值得做。
