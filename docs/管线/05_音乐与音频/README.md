# 05 · 音乐与音频 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

让音乐、音效、配音、混音和 UE 集成成为可交付、可本地化的管线。

## 什么时候用

在当前阶段的**这个管线**需要产出/验收时使用；不要等所有前置 100% 完成才开始概念探索。

## 输入

- 剧本/台词
- 分镜 cue
- 美术氛围
- 平台/响度标准

## 输出

- 主题/stems
- 音效库
- 配音/多语言
- 混音/母带
- MetaSounds/Wwise 集成

## 步骤

1. 写音乐 brief：情绪、参考、BPM、调性、循环。
2. 做主题 demo → 正式编曲 → stems/自适应层。
3. 按 SFX- 列音效，按 VO- 列配音；标语言/情绪/时长。
4. 混音/响度检查；平台/耳机/电视验证。
5. 集成 MetaSounds/Wwise，跑游戏内触发测试。

## 验收闸门

**G5 音频可集成**

## 工具

- DAW
- MetaSounds/Wwise
- AI 音频（可选）
- gamecheck gate audio

## 交接

P6 内容：对白/战斗/环境触发；P7 发行：PV 混音/字幕。

## 文件位置

- 文档：docs/
- 阶段版本/冻结：stages/05_音乐与音频/
- 证据：docs/evidence/
- 资产：assets/、art/Source/、art/Export/

## 注意事项

交付 stems 和循环点，不只交一个混音文件；AI 音频需保留授权与提示词。
