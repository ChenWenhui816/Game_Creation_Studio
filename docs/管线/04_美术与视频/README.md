# 04 · 美术与视频 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

建立资产工厂与视觉风格，同时产出游戏内资产、分镜/Previz 和营销 PV。

## 什么时候用

在当前阶段的**这个管线**需要产出/验收时使用；不要等所有前置 100% 完成才开始概念探索。

## 输入

- 美术圣经
- 剧本/分镜
- 白模比例
- 资产清单

## 输出

- 概念/角色/场景/道具/UI/VFX
- UE 导入资产
- 分镜/Animatic/Previz
- PV 母版与多语言版本

## 步骤

1. AI/手绘概念 → 风格锚点 → 3 视角/色板/材质。
2. Blender 建模/重拓扑/UV → Substance 贴图 → UE 导入。
3. 每个资产登记：来源、许可证、面数、贴图、LOD、碰撞、导入设置。
4. 按 SH- 镜头做分镜/Animatic；游戏内过场进 UE Sequencer。
5. PV：UE MRQ 或 AI 视频 → 剪辑/字幕/混音 → 多平台比例。

## 验收闸门

**G4 风格与管线锁定**

## 工具

- Blender
- Substance
- ComfyUI/Scenario
- UE MCP
- Movie Render Queue

## 交接

P5 音乐：MUS/SFX/VO cue；P6 内容：可用资产库。

## 文件位置

- 文档：docs/
- 阶段版本/冻结：stages/04_美术与视频/
- 证据：docs/evidence/
- 资产：assets/、art/Source/、art/Export/

## 注意事项

AI 生成 3D 必须重拓扑/UV；AI 视频只做概念/营销，不替代游戏内镜头。
