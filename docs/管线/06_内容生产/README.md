# 06 · 内容生产 使用说明

> 中文为主 / Chinese primary · English summary at the bottom.

## 目标

把白模、资产、剧本、音频组装成完整可通关的游戏。

## 什么时候用

在当前阶段的**这个管线**需要产出/验收时使用；不要等所有前置 100% 完成才开始概念探索。

## 输入

- 白模
- 资产库
- 剧本/任务
- 音频

## 输出

- 全部关卡
- 敌人/Boss/收集
- 剧情/任务/UI
- 周报与验收单

## 步骤

1. 按关卡表排产；每关先做灰盒→资产替换→玩法调优。
2. 每周固定：截图巡览、性能、缺陷、周报。
3. 每关写验收清单并勾选；资产走验收单。
4. 回归测试：键鼠/手柄、存档、崩溃、性能。
5. 进入上线管线前做全流程通关。

## 验收闸门

**G6 全流程通关**

## 工具

- UE
- 资产库
- 每日截图巡览
- QA 清单

## 交接

P7 上线：构建、商店、认证、多语言。

## 文件位置

- 文档：docs/
- 阶段版本/冻结：stages/06_内容生产/
- 证据：docs/evidence/
- 资产：assets/、art/Source/、art/Export/

## 注意事项

内容生产阶段不再改核心机制；要改先走变更单。
