# 13 多语言商店素材清单

> 用途：G5 上线闸门的第二张判定表，覆盖“中文 + English”两种商店页与素材。
> 用法：全部勾选才允许发布；任一项不能勾，在后方写原因与计划日期。
> 文件命名与尺寸是 `gamecheck.py gate release` 的机器判据，改名/改尺寸会导致闸门失败。
> 平台尺寸与政策**以官方文档为准**（Steamworks / Epic / itch.io），本清单只固定“我们自己的交付标准”。

## 语言矩阵

| 语言 | 界面 | 字幕 | 配音 | 商店页文案 | 商店截图 | 预告片字幕 | 备注 |
|---|---|---|---|---|---|---|---|
| 中文（简体） | 是 | 是 | 【待填】否 | `store/store_text_zh.md` | `store/screenshot_zh_*.png` | `store/trailer_zh.srt` | 首发必须 |
| English | 是 | 是 | 【待填】否 | `store/store_text_en.md` | `store/screenshot_en_*.png` | `store/trailer_en.srt` | 首发必须 |
| 【待填】其他语言 | 【待填】 | 【待填】 | 【待填】 | `store/store_text_<lang>.md` | 【待填】 | 【待填】 | 上线后追加 |

规则：
- 首发只承诺中文 + English；第三种语言先不加，避免翻译与校对翻倍。
- “界面/字幕/配音”三栏分别勾选，不能用“支持中文”一句糊过去。
- 商店页文案必须人工校对，禁止直接机翻；两种语言各找一个人读一遍。

## 商店文案

| 文件 | 语言 | 必须包含 | 字数 | 校对 |
|---|---|---|---|---|
| `store/store_text_zh.md` | 中文 | 一句话卖点 / 长描述 / 标签 / 系统需求 / FAQ | 500–1200 字 | 【待填】 |
| `store/store_text_en.md` | English | one-liner / long description / tags / system requirements / FAQ | 300–800 words | 【待填】 |

硬性要求：
- [ ] 两种语言的“一句话卖点”都 ≤20 个词，且含 1 个动词
- [ ] 两种语言的长描述都包含：玩法 3 句、内容量 1 句、时长 1 句、平台 1 句
- [ ] 标签 ≥5 个，中英一致（类型 + 主题 + 玩法）
- [ ] 系统需求按实机测试填写，不是抄同类游戏
- [ ] 两种语言都写了“Demo 内容范围”与“是否支持手柄”
- [ ] 两种语言都没有“史上最佳”“必玩”等无法验证的宣传语
- [ ] 两种语言都由第二个人通读，错别字为 0

## 截图与预告片

| 素材 | 文件 | 数量 | 规格 | 本地化要求 |
|---|---|---|---|---|
| 商店截图（中文） | `store/screenshot_zh_01.png` … `_05.png` | ≥5 | 1920×1080 PNG | UI 为中文，不含英文残留 |
| 商店截图（English） | `store/screenshot_en_01.png` … `_05.png` | ≥5 | 1920×1080 PNG | UI 为英文，不含中文残留 |
| 预告片 | `store/trailer.mp4` | 1 | 30–60 s，H.264，1080p | 前 5 s 出现玩法画面，静音也能看懂 |
| 预告片字幕（中文） | `store/trailer_zh.srt` | 1 | UTF-8，时间轴对齐 | 与画面同步 |
| 预告片字幕（English） | `store/trailer_en.srt` | 1 | UTF-8，时间轴对齐 | 与画面同步 |

规则：
- 截图里不出现开发中占位符、控制台、debug 文字、未授权素材。
- 截图展示“玩家实际操作的画面”，不要只放概念图或 Logo。
- 至少 1 张截图含完整 HUD，至少 1 张展示核心机制。
- 预告片与截图使用同一版本构建，避免“预告是旧版”的投诉。

## 胶囊图与素材

| 素材 | 文件 | 尺寸（px） | 文字规则 |
|---|---|---|---|
| Header capsule | `store/header.png` | 460×215 | 可含游戏名，字不压边 |
| Small capsule | `store/small.png` | 231×87 | 只放 1 个主体，缩到最小可辨认 |
| Main capsule | `store/main.png` | 616×353 | 标题字不超过画面 1/3 |
| Vertical capsule | `store/vertical.png` | 374×448 | 与 Library 同构图 |
| Library capsule | `store/library.png` | 600×900 | 竖版主视觉，无小字 |
| 页面背景 | `store/page_bg.png` | 1438×810 | 无文字，压暗后仍可读 |

规则：
- 胶囊图优先“无文字/少文字”：Steam 会在不同语言页面叠加标题，图内文字容易被裁切或重复。
- 必须缩到 231×87 预览一次，主体仍可辨认才算合格。
- 所有素材记录来源与授权，AI 生成素材写进 `docs/02_美术圣经.md` 的“禁止项/来源”一节。

## 元数据与合规

- [ ] 支持语言列表（界面/字幕/配音）与商店页声明一致
- [ ] 年龄分级问卷已按实际内容填写（暴力/恐怖/语言）
- [ ] 隐私政策已写好（收集崩溃/遥测数据时必须有）
- [ ] EULA / 用户协议已准备（如需要）
- [ ] AI 生成素材的来源与使用条款已记录（模型/版本/日期/许可）
- [ ] 字体为商用授权（含中文字体与英文字体）
- [ ] 音乐与音效有授权凭证（含免费素材的许可类型）
- [ ] 第三方插件/资产许可合规（UE EULA、Common UI、LFS 等）
- [ ] 制作人员名单（Credits）中英双语齐全
- [ ] 分区定价与发行地区已确认（以平台后台为准）

- [ ] English 商店页已在平台后台预览通过（无溢出、无错字、无缺图）
- [ ] 两种语言的截图、预告片字幕、胶囊图均已上传
- [ ] 两种语言的商店文案互相对照，内容量与卖点一致
- [ ] 所有链接（官网/Discord/社交）中英页面均无 404
- [ ] 商店页的“支持语言”与游戏内实际语言一致
- [ ] 本地化文本已抽表（无硬编码），中英切换不重启
- [ ] 中英文本在 1080p 下无溢出、无缺字（CJK 字体已包含）
- [ ] `python scripts/gamecheck.py gate release --root .` 退出码 0
- [ ] 发布前 24 小时由用户做 D3 验收并记录在交付单
