## 材质与光照
| 项 | 值 | 说明 |
|---|---|---|
| 全局光照 | Lumen（GI + 反射） | 不烘焙光照贴图 |
| 阴影 | 虚拟阴影贴图 | 同屏移动光源 ≤2 个 |
| 主光方向 | 左前上 45°（方位 -45°、高度角 45°） | 全项目一致，不许逐关改 |
| 主光 / 补光 / 点光色温 | 4800–5600 K / 7000–9000 K / 2200 K | 补光只提亮暗部；点光（灯焰）半径 4–6 m |
| 粗糙度范围 | 0.20（金属）–0.90（布） | 中间值写区间，不写"0.5 左右" |
| 金属度 | 只给真金属，取 0 或 1 | 过渡区用贴图，不用中间值 |
| 风格化程度 | 贴图不画高光与阴影 | Albedo 明度 0.2–0.8，全交给引擎 |
| 雾 | 指数高度雾，浓度 0.02–0.05 | 远景靠雾分层，不靠贴图 |

## 禁止项
| 类别 | 禁止内容 | 为什么 |
|---|---|---|
| 反向提示词 | text, watermark, logo, extra limbs, extra fingers, photoreal skin, cartoon outline, oversaturated, bloom, vignette, depth of field | 出现即重出，不许修 |
| 禁用材质 | Unlit 材质（UI/VFX 除外）、双层透明、视差/置换贴图、自定义光照模型 | 破坏 Lumen 一致性、性能不可控 |
| 禁用后处理 | Bloom 强度 >0.8、色差、胶片颗粒 >0.15、运动模糊、全屏暗角 | 掩盖资产问题且吃性能 |
| 禁用贴图 | 8K、sRGB 勾错的法线、含文字或水印的贴图 | 显存与正确性问题 |
| 禁用模型 | AI 直出网格、单角色独立 Skeleton、道具超 8 万面 | 拓扑/复用/预算 |
| 流程禁止 | 跳过验收单、清单外资产进关卡、直接改 UE 资产不回写源文件 | 无法追溯与复现 |
