# 12 Demo 上线清单

> 用法：G5 的唯一判定表。**全部勾选才允许点发布按钮**；任一项不能勾，在后方写原因与计划日期。
> 平台费用、审核时长、分成比例、素材尺寸**一律以官方文档为准**（Steamworks / Epic / itch.io），本清单只规定“什么时候做、做到什么程度”。

## 账号与资质

- [ ] Steamworks 账号已注册完成（个人/公司主体与实际一致）
- [ ] 应用费已支付并记录凭证（金额以官方为准）
- [ ] 税务信息已填写并通过审核（W-8BEN 或本地等效表格）
- [ ] 收款银行账户已填写并验证通过
- [ ] 开发者身份验证（身份证/银行账单）已通过
- [ ] 应用已创建，AppID 与商店页 URL 已记录进项目周报
- [ ] itch.io 账号（用于 Demo 页/试玩招募，如需要）
- [ ] Epic 开发者账号（计划上 Epic 时才需要）

## 商店页

- [ ] 商店页已公开 ≥6 个月（愿望单积累期）
- [ ] 简介含 20 字以内的一句话卖点，含 1 个动词
- [ ] 标签已选 ≥5 个（类型 + 主题 + 玩法），与同类爆款对齐
- [ ] 系统需求（最低/推荐）已按实机测试填写，不是抄别的游戏
- [ ] 支持语言已明确（界面/字幕/配音三栏分别勾选）
- [ ] 预告片已上传，前 5 s 出现玩法画面
- [ ] 截图 ≥5 张，1920×1080，图内不含需要翻译的文字
- [ ] 商店页所有链接、社交账号、Discord 邀请均无 404
- [ ] 商店页文案中英两版都由第二个人读过，无错别字
- [ ] `docs/13_多语言商店素材清单.md` 全部勾选
- [ ] 两种语言的截图、预告片字幕、胶囊图已上传

## 构建与认证

- [ ] Shipping 构建打包成功（`build.bat`，参数固定）
- [ ] 打包记录已写入交付单：版本号、commit、包大小、耗时
- [ ] 冒烟 5 项通过：启动 / 进关 / 存读档 / 退出 / 设置保存
- [ ] 提审 build review 已通过（时长以官方为准，预留 2 周）
- [ ] 新机器从零演练通过（无缺失 DLL / VC 运行库 / 管理员权限要求）
- [ ] 首 30 min 全流程无崩溃（崩溃率 0）
- [ ] 云存档已配置并双机验证（换机读档成功）
- [ ] 成就触发点已埋 ≥8 个，后台已配置且能被触发
- [ ] 手柄可完成全部操作与菜单导航（拔鼠标验证）
- [ ] 键鼠可完成全部操作与菜单导航（不插手柄验证）
- [ ] 键鼠/手柄热切换提示在 0.5 s 内更新
- [ ] 按键重映射可保存、重启后生效
- [ ] 上一版可回滚 build 已在后台可用

## 商店素材

- [ ] 主视觉（Header capsule）已上传，尺寸按官方要求
- [ ] 小图（Small capsule）已上传，只放 1 个主体
- [ ] 大图（Main capsule）已上传，标题字不超过画面 1/3
- [ ] 竖向海报（Vertical capsule）已上传
- [ ] 库图（Library capsule）已上传，与竖版同构图
- [ ] 截图 ≥5 张，其中至少 1 张含实际 UI
- [ ] 预告片 30–60 s，静音也能看懂
- [ ] 素材在缩到 231×87 时主体仍可辨认（缩小预览验证过）

## 法律与合规

- [ ] 所有美术素材可商用（自制/购买/授权，凭证存档）
- [ ] AI 生成素材已记录来源与使用条款，必要时在商店页说明
- [ ] 字体为商用授权（含中文字体）
- [ ] 音乐与音效有授权凭证（含免费素材的许可类型）
- [ ] 第三方插件/资产许可合规（UE EULA、LFS、CommonUI 等）
- [ ] 隐私政策与最终用户协议（收集数据的游戏必需）
- [ ] 内容描述与年龄分级已按平台问卷如实填写（暴力/恐怖等）
- [ ] 游戏名已做商标与商店重名检索

## 上线演练

- [ ] T-14 → T+1 演练表已排期（见 `references/05-打磨与Demo上线.md` 步骤 14）
- [ ] 发售日期已锁定，且商店页显示的日期与之一致
- [ ] 公告与社交媒体文案已写好并请人读一遍
- [ ] 回滚包与回滚步骤已写成一张纸，能 10 分钟内执行
- [ ] 首发当天值守时间已确定（至少覆盖上线后 4 小时）
- [ ] 反馈渠道与差评回复口径已定（不承诺做不到的事）
- [ ] 首日补丁方案已预备（只做崩溃/卡关修复）
- [ ] T+1 反馈分类表模板已就绪（热修 / 下个补丁 / 不做）
- [ ] 全部勾选后，由用户做 D3 验收决策并记录在交付单
