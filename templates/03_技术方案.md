### 输入映射（键鼠 + 手柄，两套都必须可用）

| 动作 | 键鼠 | 手柄 | Enhanced Input 资产 | 备注 |
|---|---|---|---|---|
| 移动 | WASD | 左摇杆 | IA_Move（Axis2D） | 死区 0.2 |
| 视角 | 鼠标 X/Y | 右摇杆 | IA_Look（Axis2D） | 灵敏度 0.5 / 0.7 |
| 跳跃 | Space | A | IA_Jump | Started 触发，不用 Triggered |
| 冲刺 | Shift | B | IA_Sprint | Hold/Toggle 二选一 |
| 攻击 | 左键 | X | IA_Attack | 与交互键隔离 |
| 交互 | E | Y | IA_Interact | 可加 Hold 0.3 s |
| 暂停 | Esc | Start | IA_Pause | 过场禁用 |

- 提示图标：`UI/InputPrompts` 下按设备分两套，切换设备 0.5 s 内更新。
- 重映射：设置页写 `UserSettings`，重启后仍生效；恢复默认要二次确认。
- 验收：拔鼠标可通关、拔手柄可通关、热切换无卡死（见 `10_测试记录`）。

## 数据与存档

| 项 | 方案 |
|---|---|
| 存档类 | 【示例】UGameSave : USaveGame |
| SaveVersion | 从 1 开始；每加字段 +1，迁移函数集中在一处 |
| 槽位 | 主槽 + `_bak` 备份槽，加载失败回退 |
| 写盘时机 | 只在检查点触发时写（禁止每帧/每门写盘） |
| 云存档 | Auto-Cloud 映射 `Saved/SaveGames`（以 Steamworks 官方为准） |
| 关键约束 | 存 FName ID，不存 Actor 指针 |

## MCP 与自动化

| 操作 | 等级 | 留痕要求 |
|---|---|---|
| 只读查询、跑测试、打包、截图、改 DataTable 数值 | 白名单 | 记命令 + 影响文件 |
| 新建蓝图/材质/关卡、改项目设置、批量重命名 | 灰区 | 人工复核 diff + 截图 |
| 改 .uasset/.umap 二进制、删资产、改插件列表、并行写同一资产 | 黑名单 | 禁止 |

MCP 服务端能力因实现而异，执行前确认该操作在服务端能力清单内；写操作前先 commit。

## 版本管理

| 项 | 规则 |
|---|---|
| 分支 | main（可打包）/ dev（日常）/ feature/<名> / hotfix/<版本> |
| LFS | .uasset/.umap/.fbx/.png/.psd/.wav/.blend 走 LFS；.umap/.uasset 加锁 |
| 提交 | 每完成一个可验证动作提交一次；信息用 `feat/fix/docs/test/chore` + 一句中文 |
| 版本号 | 每次出包打 tag：v0.1.0（G2）/ v0.2.0（G3）/ v1.0.0（上线） |
| 单文件 | 【待填】上限（以 GitHub 官方为准，默认 <100 MB） |

## 风险与回滚

| 风险 | 概率 | 影响 | 预防 | 回滚 |
|---|---|---|---|---|
| 改引擎版本导致资产损坏 | 低 | 高 | 锁定次版本号，升级前整包备份 | 回退到上个 tag + 用旧引擎打开 |
| 数值表与编辑器不一致 | 高 | 中 | 编辑器值必须能在数值表找到 | 以数值表为准重置资产 |
| 存档结构变更崩老档 | 中 | 高 | SaveVersion + 迁移函数 | 加载失败回退 `_bak` 槽 |
| 性能不达标 | 中 | 高 | 每轮末尾测一次 | 按优化顺序砍，最后才降分辨率 |
| 【待填】 | 【待填】 | 【待填】 | 【待填】 | 【待填】 |
